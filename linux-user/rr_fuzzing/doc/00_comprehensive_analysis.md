## 🎯 核心问题分析

### 执行路径差异问题

**问题**: 为什么执行完全相同的命令 `ls`，记录时产生110条系统调用，重放时只产生84条？

**答案**: 即使命令行完全相同，程序的执行路径仍可能因为**环境状态差异**而不同。

#### 差异原因分析

1. **文件系统状态差异**
   ```bash
   # 记录时: /tmp/某文件存在
   # 重放时: /tmp/某文件不存在
   # 结果: access()调用返回不同结果，影响后续执行路径
   ```

2. **动态链接器行为**
   ```bash
   # 不同的库加载顺序或可用性
   # 导致不同的dlopen/dlsym调用序列
   ```

3. **环境变量差异**
   ```bash
   # LD_DEBUG, PATH, LANG等环境变量的变化
   # 影响程序初始化和执行路径
   ```

4. **进程ID和时间戳**
   ```bash
   # getpid(), gettimeofday()等返回不同值
   # 可能影响程序的条件分支
   ```

## 🎯 设计哲学与原则

### 当前实现的设计选择

#### 1. **功能正确 > 精确重放**
```
选择: 优先保证程序功能正确，而非100%精确重放
原因: 实用性更强，满足调试和漏洞复现需求
代价: 无法用于需要精确时序的场景
```

#### 2. **真实执行 > 数据恢复**
```
选择: 让系统调用真实执行，而不是返回记录数据
原因: 简化实现，提高兼容性和稳定性
代价: 无法重现依赖特定数据的行为
```

#### 3. **句柄映射 > 环境模拟**
```
选择: 重点解决句柄映射问题，而非完整环境模拟
原因: 句柄不一致是最常见的重放失败原因
代价: 仍然受环境变化影响
```
